# README

Ceci est un projet **EPICUR** de l'**UHA 4.0** de début d'année 401 en 2023.

## Projet

Il s'agit de présenter la formation universitaire UHA 4.0 par une courte vidéo soutenu par une musique et/ou de la voix.

Projet réalisé dans le cadre de de la « Scrum Week » :

## 🎮 Fonctionnalités du diaporama

Le lecteur intègre une barre de contrôle complète permettant de naviguer aisément entre les diapositives :
* ▶️ **Lecture automatique** (*Play*)
* ⏸️ **Pause**
* ⏹️ **Arrêt** (*Stop*)
* 🔄 **Réinitialisation / Boucle**
* ⬅️ ➡️ **Navigation manuelle** (Diapositive précédente / suivante)

## 🛠️ Technologies utilisées

* **HTML5** : Structuration des diapositives et des contrôles.
* **CSS3** : Mise en page, animations et design du slider.
* **JavaScript** : Logique de défilement automatique, gestion des événements et navigation interactive.
* **GitHub Pages** : Hébergement du projet.

> Slide 3

Présentation UHA 4.0
: Cette école, qui ouvrira ses portes en septembre 2015, proposera des formations en alternance dans les métiers du numérique. Elle s’adresse aux étudiants de niveau bac à bac + 3, ainsi qu’aux demandeurs d’emploi. Les formations seront dispensées par des professionnels du secteur et seront axées sur les compétences pratiques. Les étudiants pourront ainsi acquérir une expérience concrète en travaillant sur des projets réels. Les formations proposées par l’UHA 4.0 seront reconnues par l’État et permettront aux étudiants d’obtenir un diplôme de niveau bac + 2 ou bac + 3. Les inscriptions sont ouvertes dès maintenant sur le site de l’université.
